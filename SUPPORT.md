# Support

- **Documentation:** [hsrcpay.com/docs](https://hsrcpay.com/docs)
- **Bugs and feature requests for this SDK:** open a [GitHub issue](https://github.com/hsrcpay/node-sdk/issues/new/choose).
- **Account, billing or API questions:** [hsrcpay.com/contact](https://hsrcpay.com/contact)
- **Security issues:** see [SECURITY.md](SECURITY.md), do not use public issues.

When reporting a bug include the SDK version, runtime (Bun or Node.js version), a minimal reproduction, and the
request id or error body if you have one. Remove API keys and personal data first.
